# Казахский орнамент (ою-өрнек) в Clarity

Библиотека: `src/brand/Ornament.tsx`, стили: `src/styles/ornaments.css`, превью: `npx tsx scripts/ornament-preview.mts` → `scripts/avatar/out/ornaments/*.png`.

## Мотивы

| Мотив | Где | Смысл |
|---|---|---|
| **қошқар мүйіз** (бараний рог) — пара завитков, расходящихся наружу от общего стебля | `OrnamentBand`, `OrnamentPattern`, `OrnamentCorner` | главный казахский мотив: достаток, благополучие, уважение к дому и гостю |
| **төрт құлақ / күн** — четыре пары рогов из центра, круглый медальон | `Rosette` | «четыре стороны света», солнце, полнота и защита |
| **қос мүйіз** — две пары рогов, зеркальные вверх/вниз | `OrnamentDivider` | связь и равновесие |

Геометрия строится кодом: один рог — логарифмическая спираль (≈1,2–1,4 витка), сглаженная кривыми Безье; второй рог — зеркало, остальные — повороты. Мотив лежит в `<defs>` один раз и повторяется через `<use>` (все пути вместе < 10 КБ).

## Компоненты

Все — `aria-hidden`, `pointer-events: none`, цвет по умолчанию `currentColor`; общие пропы `className`, `color`, `accent` (ромбики/точки), `opacity`.

- `OrnamentBand { height=22 }` — бесшовная горизонтальная кайма на всю ширину (рога вверх/вниз чередуются).
- `OrnamentCorner { size=72, corner='tl'|'tr'|'bl'|'br' }` — уголок; `.kz-corner` позиционирует его абсолютно в своём углу (родитель — `position: relative`).
- `OrnamentPattern { tile=64 }` — едва заметный фон, заполняет позиционированного родителя (контент родителя поднять `position: relative; z-index: 1`).
- `OrnamentDivider` — тонкие линии с затуханием + маленький медальон по центру (max 360px).
- `Rosette { size=96 }` — круглый медальон (экран поздравления, пустые состояния, логотипная зона).

## Цвета и классы

`--kz-gold #C9A23A`, `--kz-gold-soft #E7C86A`, `--kz-sky #00A3C4` (голубой флага) + `--teal` приложения.
Классы цвета: `.kz-gold`, `.kz-teal`, `.kz-sky`; `.kz-on-dark` — мягкое золото и чуть большая непрозрачность для тёмного бирюзового фона (голосовой звонок, вход).

## Правила использования

- Спокойно и медицински: тонкие линии, золото/бирюза, без сплошных заливок больших площадей.
- Непрозрачность на светлом фоне: фон 0.08–0.12 (по умолчанию 0.1), кайма ~0.55, уголки ~0.6, разделитель ~0.7; на тёмном — фон 0.14, кайма 0.75.
- Не ставить орнамент под текст клинических инструкций и в поля форм; не больше одного «крупного» элемента (Rosette/угловые) на экран.
- Орнамент — декор: никакой информации в нём не передаётся; при печати фон и уголки скрываются.

Пример:

```tsx
<section className="hero" style={{ position: 'relative' }}>
  <OrnamentPattern className="kz-teal" />
  <OrnamentBand className="kz-gold" height={18} />
</section>
<div className="call-screen"><OrnamentCorner corner="tr" className="kz-on-dark" /></div>
```
