# Аватар «Аружан»

Реалистичный говорящий аватар ИИ-помощника Clarity. Альтернатива роботу «Клэри» (выбор — `AvatarId`).

## Что это
- **Синтетический человек.** Портрет сгенерирован нейросетью и не изображает реального человека; похожесть на конкретных людей в промпте прямо запрещена.
- **Не врач.** Белый халат — визуальный код клиники, а не заявление о квалификации. Бейдж «ИИ» / «ЖИ» (казахский: *жасанды интеллект*) виден всегда, в `aria-label` и `title` написано «ИИ-помощник (не врач)» / «ЖИ-көмекші (дәрігер емес)». Отключать бейдж (`showBadge={false}`) можно только там, где рядом явно есть пометка об ИИ.
- Национальный элемент: изумрудный бархатный камзол с золотой вышивкой «қошқар мүйіз», серебряные серьги. Без логотипов, текста, бейджа с именем и красного креста.

## Генерация
| Шаг | Модель | Попыток | Успешно | Стоимость |
|---|---|---|---|---|
| Базовый портрет | `google/gemini-3-pro-image` (OpenRouter) | 3 | 1 | ≈ $0.14 |
| Правки рта/моргания | `google/gemini-3.1-flash-image` | 9 | 0 | $0 |

Итого 1 успешная генерация (≈ $0.14). Правки кадров не прошли: OpenRouter вернул `402` (на аккаунте почти не осталось кредитов: `in_flight_budget_exhausted`). Поэтому кадры визем и моргания **синтезированы из базового фото геометрической деформацией** (см. ниже). Если пополнить баланс, можно запустить правки: `process.mts` сам возьмёт сгенерированные кадры вместо синтезированных.

Промпт портрета — `BASE_PROMPT` в `scripts/avatar/gen-base.mts`; промпты правок — `FRAME_PROMPTS` в `scripts/avatar/gen-frames.mts` («Edit this exact photograph… Change ONLY the mouth: …»).

## Синтез кадров (`scripts/avatar/process.mts`)
- База нормализуется до 720×900 (cover), экспорт `base.webp` (q82) и `base-sm.webp` (360×450).
- **Рот** (A, O, E, U, M): находится линия смыкания губ (самый тёмный пиксель в столбце, сглаженный); обратным отображением с билинейной выборкой нижняя губа и подбородок опускаются на `d`, верхняя губа приподнимается на `u` (профиль по ширине рта `(1−t²)^shape`), рот сужается/растягивается по горизонтали (`s`), в проёме рисуется полость и зубы. M — сжатие губ к линии смыкания.
- **Моргание:** кожа верхнего века растягивается вниз до нижнего века (линия ресниц оказывается внизу), к уголкам глаза деформация гаснет.
- Деформация затухает к краям общего бокса, поэтому патчи (`mouth-*.webp`, `eyes-closed.webp`, WebP с мягкой эллиптической альфой) накладываются без швов.
- Если есть файл `scripts/avatar/out/frame-<k>.png` (сгенерированная правка), он совмещается с базой перебором сдвига ±12 px по SAD на неизменной области (глаза/нос для рта, рот/подбородок для моргания) и используется вместо синтеза.
- Пишет `public/avatars/aruzhan/manifest.json` и контактный лист `scripts/avatar/out/contact.png` для проверки.
- Все ассеты ≈ 85 КБ.

## Компонент
`src/assistant/RealisticAvatar.tsx` (стили `src/styles/avatar-real.css`), подключается через `AssistantAvatar` (`avatar="aruzhan"`).
- Липсинк: в `requestAnimationFrame` (только пока `speaking`) читается `mouthSource()` (или проп `mouth`), веса A = open·(1−round)·(1−wide), O = open·round, U = round·(1−open), E = wide, M = closed, сумма ≤ 1, сглаживание ~45 мс; веса переводятся в прозрачности слоёв с учётом порядка наложения. Без речи — базовая закрытая улыбка.
- Моргание каждые 2,5–6 с (120 мс); дыхание (scale 1→1.006) и покачивание (±0,4°); `listening` — светящееся кольцо и наклон; `thinking` — пузырь с точками; `mood="concerned"` — чуть приглушённее.
- `framing="head"` — круглый кроп лица (координаты `face` в манифесте). `prefers-reduced-motion` отключает анимации.
- Координаты патчей продублированы в константе `M` компонента — при перегенерации синхронизируйте с `manifest.json`.

## Как перегенерировать
```bash
export PATH=$HOME/.local/node/bin:$PATH
npx tsx scripts/avatar/gen-base.mts base-2          # новый кандидат портрета (≈ $0.14), выбрать и сохранить как out/base-1.png
npx tsx scripts/avatar/gen-frames.mts a o e u m blink  # правки кадров (flash; --model=pro для pro)
npx tsx scripts/avatar/process.mts                  # ассеты + манифест + контактный лист
```
Ключ берётся из `LLM_API_KEY` в `.env` во время запуска и не печатается. Сырые файлы — в `scripts/avatar/out/` (в `.gitignore`); в репозиторий попадает только `public/avatars/aruzhan/`. При смене базового портрета заново измерьте координаты лица (`MOUTH`, `EYES`, боксы) в `process.mts`.

## Лицензия и использование
Изображение сгенерировано ИИ для прототипа (синтетические данные хакатона). Использовать только как аватар ИИ-помощника Clarity с видимой пометкой ИИ; не выдавать за фото сотрудника клиники или реального врача.
