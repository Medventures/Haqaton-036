# Сценарий защиты (3–4 минуты)

Перед показом: `npm run dev`, откройте `http://localhost:5173`. Для чистого старта нажмите ↺ у профиля (сброс маршрута демо-пациента). Включите звук: Клэри говорит.

## 1. Проблема (15 с)

«Перед МРТ с контрастом пациент должен проверить противопоказания, сдать креатинин и подготовиться. Ошибки → отмены, переносы и звонки в клинику. После — непонятное заключение».

## 1a. Регистрация и знакомство (40 с)

1. Экран входа → **«Я пациент — первый вход»** (или «Войти через Google», если настроен OAuth).
2. Знакомство: имя → год рождения и пол («нужны для расчёта функции почек») → время МРТ → «впервые», волнение 😟, «замкнутое пространство» → голос вкл. → согласия.
3. Значок **«Знакомство»** с конфетти. Главная показывает один следующий шаг и «До МРТ — N дней».

## 1b. Голосовой разговор (30 с)

**«Поговорить голосом»** → «Начать разговор». Скажите: «Я очень боюсь замкнутых пространств». Клэри отвечает с сочувствием и сама слушает дальше. Скажите «запиши меня к неврологу» — появятся слоты. Кнопка «Перебить» или пробел останавливают речь.

## 2. Клэри и проверка (60 с)

1. **Поговорить с Клэри.** Клэри представляется как ИИ, «не врач», и показывает визит.
2. **Пройти проверку перед МРТ.** Отвечайте **текстом**, не кнопками:
   - «нет» — кардиостимулятор;
   - «не помню точно» — импланты → «Ничего страшного… координатор уточнит»;
   - посреди анкеты: «**Можно ли пить воду перед МРТ?**» → ответ из базы знаний со ссылкой на источник и возврат к анкете;
   - «да, у меня астма» → персональный пункт «возьмите ингалятор»;
   - «да, боюсь замкнутых пространств» → пункт про клаустрофобию.
3. Анализ: «да» → «креатинин 84» → «сдавала 20.09». Появится сводка: рСКФ ≈ 69 (CKD-EPI 2021), давность, флаги.
4. Откройте **Координатор** (меню слева): задача уже в очереди с приоритетом.

> Ключевая фраза: «ИИ не решает, можно ли вводить контраст. Он собирает ответы, считает рСКФ по формуле и передаёт сомнения врачу. Все правила — детерминированные и покрыты тестами».

## 3. Подготовка и напоминания (40 с)

1. «Как подготовиться» — персональный план по фазам, отметки.
2. «Настроить напоминания» → «За 3 дня, за день и за 3 часа». Скачайте `.ics`.
3. **Демо-время** в шапке → «Накануне (за 23 ч)». Придут уведомления и 🔔, на главной — баннер самопроверки дня визита.
4. «В день МРТ» → самопроверка: ответ «Нет» на вопрос о еде → координатор получает задачу «Нарушение подготовки» **до** приезда пациента.

## 4. Заключение и запись (50 с)

1. «Через 2 дня после МРТ» → «Объяснить заключение» → **Пример: есть находки**. Глиоз — «частая находка», демиелинизация — к неврологу; «без патологического накопления» распознано как отрицание.
2. **Пример: тревожный** → уровень «Срочно», нейрохирург, срочная задача координатору, советы о симптомах, слоты с ближайшего дня.
3. Выберите время → «да» → запись.

## 5. Безопасность (15 с)

Напишите «**мне трудно дышать**» → 103/112, срочная задача. Напишите «можно ли мне не пить таблетки?» → «это решает только врач».

## 5a. Рабочее место врача (30 с)

Выйдите (меню профиля) → **«Сотрудник клиники»** → **Пациенты**. Новый пациент уже в реестре. Откройте карточку: ответы анкеты с подсветкой, креатинин и рСКФ, заключение с маркерами, история действий, кнопка «Печать».

## 6. Метрики (20 с)

**Метрики** → 4 показателя кейса, база и группа Clarity, воронка, причины отмен. Подчеркните: история смоделирована, эффект заявим только после пилота. Формулы — в [METRICS.md](METRICS.md).

## Чего не говорить

- «ИИ проверяет безопасность / допускает к контрасту».
- «ИИ интерпретирует снимки» — он объясняет текст заключения.
- «Мы снизили отмены на X%» — это демо-данные.
- «Сообщение/SMS отправлено» — доставка идёт в приложение, в уведомления браузера и через `.ics`.

## Если нет интернета или ключа LLM

Все сценарии работают в режиме правил. Внизу панели Клэри пишет «работает в режиме правил». Это аргумент надёжности: критическая логика не зависит от модели.
